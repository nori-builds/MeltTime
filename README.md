# おくすりタイマー（MeltTime）

子どもが毎朝飲む舌下免疫療法の薬（シダキュア・ミティキュアなど）のための、ワンタップで使えるタイマーです。

> このファイルを、このアプリの仕様の **唯一の正（SSOT）** とします。
> 仕様を変えるときは、先にこの README を更新し、それからコードを直してください。

## かんたんな使い方

**さいしょに1回だけ**: iPhone の Safari で https://nori-builds.github.io/MeltTime/ を開き、共有ボタン →「ホーム画面に追加」。以後はホーム画面のアイコンから開きます。

**まいあさ**

1. アプリを開いて「はじめる」をタップ
2. 薬を舌の下に置いて待つ（画面はピーチ色）
3. チャイムが鳴って画面が黄色く光ったら、ごっくんと飲み込む
4. そのまま5分、うがい・飲食はしない（画面はラベンダー色）
5. チャイムが鳴って画面が緑になったら、おしまい。スタンプが自動でつきます

**こんなときは**

- 途中でやめたい → 「ながおしで やめる」を長押し（普通にタップしても止まりません）
- スタンプをつけ忘れた・消したい → カレンダーの日付を長押し
- 時間を変えたい・声を消したい → 設定画面で変えられます
- 音が鳴るか心配 → 設定の「おとの テスト」で確かめられます
- 使い方を見返したい → ホームの右上の「?」

---

## 1. 目的

舌下免疫療法では、毎回次の手順で飲みます。

1. 薬を舌の下に置いて **1分** そのままにする
2. 飲み込む
3. その後 **5分** は、うがい・飲食をしない

これまでは毎朝、1分と5分のタイマーを別々に設定していました。この手間を **ワンタップ** で済ませるのが目的です。

> 時間（1分・5分）は、薬の説明書や主治医の指示で確かめてください。アプリの設定画面で変えられます。

| 項目 | 決定 |
|---|---|
| 使う人 | 親も子どもも使う |
| 端末 | iPhone |

## 3. 機能仕様

### 3.1 タイマーの流れ

- 「はじめる」を **1回タップ** すると始まる
- **① したの した（1分）**: 終わると知らせて、自動で ② に進む
- **② おやすみ（5分）**: 終わると「おしまい！」画面になる
- 時間は **開始した時刻からの経過時間** で計算する。別のアプリに切り替えたり、アプリを開き直したりしても、ずれずに続きから表示される
- 動いている途中の状態は端末に保存され、アプリを開き直すとタイマー画面に戻る
- ① の終わりから30秒以上たって戻ってきた場合は、「ごっくん」画面は出さない

### 3.2 知らせ方

マナーモードで音が鳴らなくても分かるように、**音と、画面全体の色の変化** の両方で知らせます。

| タイミング | 画面 | 音 |
|---|---|---|
| 開始 | ピーチ色「したの したで とかしてね」 | 声「おくすりを したの したに おいてね」 |
| 1分終了 | **黄色で点滅**「ごっくん！ のみこんでね」（約4.5秒、タップで閉じる） | チャイム → 声「ごっくん してね」 |
| 5分の間 | ラベンダー色「おやすみ タイム」 | なし |
| 5分終了 | **緑**「おしまい！ よくできました」 | チャイム → 声「おしまい！ よくできました」 |

- チャイムはその場で合成するので、音のファイルはいらない
- 声は iPhone の読み上げ機能を使う（少し機械っぽい声になる）。設定でオフにできる
- iPhone のウェブアプリでは **バイブは使えない**

### 3.3 画面をつけっぱなしにする

- タイマーが動いている間は、画面が消えないようにする（Wake Lock API）
- 使えない環境では「がめんを つけたままに してね」と表示する

### 3.4 間違って触ったとき

- タイマーが動いている間に普通にタップしても、**何も起きない**
- 「ながおしで やめる」を **1.2秒長押し** したときだけ止まる
- 途中でやめた場合、スタンプはつかない

### 3.5 記録（スタンプカレンダー）

- 5分を最後まで終えると、**その日（開始した日）にスタンプが自動でつく**
- 同じ日に2回以上終えても、スタンプは1つだけ（「きょうの スタンプは もう あるよ」と表示）
- カレンダーの日付を **長押し（約0.65秒）** すると、スタンプをつけたり消したりできる。未来の日はさわれない
- 「れんぞく ○ にち」を表示する
- ホーム画面には、今日の状態（「きょうは もう のんだよ ✓」または「けさの おくすり まだだよ」）を表示する

### 3.6 設定

| 項目 | 初期値 | 範囲 |
|---|---|---|
| ① したの した | 1分 | 1〜10分 |
| ② おやすみ | 5分 | 1〜30分 |
| こえで しらせる | オン | オン／オフ |
| おとの テスト | — | 「ならす」で確かめられる |

### 3.7 つかいかた（アプリ内）

- ホームの右上（設定の左）の「?」で開く
- 内容は「まいあさの流れ（5ステップ）」と「こんなときは」。ステップの番号の色は、その場面の画面の色と同じ。①②の時間は設定の値を表示する
- **はじめて開いたときだけ自動で表示する**。閉じたら（「わかった」・✕・外側のタップ）次からは出さない

### 3.8 キャラクター

- **「おくすりの粒の子」**: 白くて丸い錠剤に、葉っぱが1枚ついた子。SVGでコードから描いているので、画像ファイルや著作権の心配はない
- ① の間は、時間がたつにつれて溶けていく
- ② の間は、溶けたまま眠る（zzz）
- おしまいでは、元に戻って笑顔になる
- スタンプもこの子の顔で、日付によって表情と背景の色が変わる（にっこり・ウインク・キラキラ・ぺろっ・てれ）
- ホーム画面のアイコンとファビコンも、この子（にっこり顔）の画像。`apple-touch-icon.png`（180×180）・`favicon.svg`・`favicon-32.png` を置いている

## 4. 作っていないもの

- サーバー、ログイン、複数の端末での同期
- プッシュ通知（画面をつけっぱなしにする方式で代わりにしている）
- 1日に2回以上の記録や、兄弟など複数人での利用
- フレームワーク（Next.js・Tailwind・shadcn/ui は使わない）

## 5. 技術構成

| 項目 | 決定 | 理由 |
|---|---|---|
| 構成 | `index.html` 1ファイル（HTML / CSS / JS をすべて中に書く）＋アイコン画像 | ビルドがいらず、置くだけで動く。長く放っておいても壊れにくい。アイコンは iPhone が確実に読めるよう、画像ファイルとして置く |
| 保存 | `localStorage`（その iPhone の中だけ） | サーバーがいらない |
| 公開 | GitHub Pages（https） | 無料。Wake Lock とホーム画面への追加には https が必要 |
| フォント | ヒラギノ丸ゴ（iPhone に最初から入っている） | 読み込みがいらない |

### 保存キー

| キー | 内容 |
|---|---|
| `melttime.settings` | `{ m1, m2, voice }` |
| `melttime.stamps` | スタンプがついた日付の配列（`YYYY-MM-DD`、端末の時刻で判定） |
| `melttime.helpSeen` | つかいかたを一度閉じたら `true` |
| `melttime.run` | 動いているタイマー `{ startAt, m1, m2, fired1 }`（止まっているときは無し） |

テストモードでは、キーの先頭が `melttime-test.` になります。

### 注意（iPhone）

- **ホーム画面から開いたときと Safari で開いたときでは、記録が別々になる**。いつもホーム画面から開く。Safari で開いているときは、その説明を画面上部に出している
- マナーモード中は、Web の音が鳴らないことがある。`navigator.audioSession.type = 'playback'` で鳴るようにしているが、iOS のバージョンによって変わる
- 音と読み上げは、最初のタップ（「はじめる」）のときに有効にしている

## 6. 開発と確認

- **テストモード**: URL の最後に `?test` をつけると、1分が5秒になる（画面に「テスト」と表示される）
- **ローカルで確認**: `.claude/launch.json` の `melttime` でローカルサーバーを立てる（http://localhost:5178/?test）

### 確認状況

| 項目 | 状況 |
|---|---|
| タイマーの流れ（① → ごっくん → ② → おしまい） | ✅ ブラウザで確認済み |
| スタンプの自動付与と、二重につかないこと | ✅ ブラウザで確認済み |
| カレンダーの長押しでの手直し、れんぞく日数 | ✅ ブラウザで確認済み |
| 「やめる」の長押し（短いタップでは止まらない） | ✅ ブラウザで確認済み |
| 設定の変更 | ✅ ブラウザで確認済み |
| iPhone でチャイムと声が鳴るか | ⬜ 実機で未確認 |
| マナーモードでも音が鳴るか | ⬜ 実機で未確認 |
| ホーム画面に追加して、画面がつけっぱなしになるか | ⬜ 実機で未確認 |
